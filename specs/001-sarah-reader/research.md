# Research

- Decision: retain Next.js 16.3.5 App Router and server-rendered homepage. Read installed project-structure and navigation guides. Rationale: preserve routes and minimize client JavaScript. Alternative: rewrite as static HTML; rejected because it duplicates booking logic.
- Decision: Cormorant Garamond for editorial headings, Allura for handwriting, DM Sans for controls, all locally packaged with Vietnamese subsets. Alternative: remote font loading; rejected for avoidable external runtime dependency.
- Decision: responsive live text over a separate decorative seaside floral image. Alternative: poster image as page; rejected for unreadable mobile text and inaccessible controls.
- Decision: shared service/contact configuration, retain existing tool routes and contact numbers. Add Lenormand consultation and retain numerology as an additional tool.
- Decision: keep dated Oct campaign with explicit past status outside its dates; do not imply a current discount.
- Decision: clipboard is optional; request stays visible and manual-copy fallback is explicit. Submission prepares a request and never records a confirmed appointment.
